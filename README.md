# lista_tarefa

Criado para fins de estudo e aprendizado, é um mini-site que permite ao usuário adicionar e marcar tarefas como concluídas, sem usar banco de dados ou local sto. 

Então tudo que o usuário adicionar será eliminado assim que a página recarregar, mas como apenas foi criado para trabalhar front-end básico, sem problemas 😁.
